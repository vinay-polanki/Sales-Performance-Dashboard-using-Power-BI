# Sales-Performance-Dashboard-using-Power-BI


This project involves the creation of a Sales Performance Dashboard using Microsoft Power BI, based on structured sales data stored in Excel (.xlsx) format. The primary objective was to provide a comprehensive and interactive overview of sales trends, customer behavior, and product performance.

The dashboard includes five key visualizations: Sales Over Time, Profit by Product Category, Top 10 Customers by Sales, Sales by Region, and Discount vs. Profit Analysis. These visual elements were carefully designed and manually configured within Power BI to enable users to explore and analyze the data from multiple business perspectives.

Utilizing Power BI’s robust features such as data transformation (Power Query), interactive slicers, custom visuals, and dynamic filtering, the dashboard provides an intuitive interface for business users. The use of Excel as the data source enabled easy integration and frequent data refreshes without complex configurations.

This manual Power BI implementation demonstrates the tool’s capability to transform raw Excel data into powerful visual insights, supporting data-driven decision-making for stakeholders across the organization.
